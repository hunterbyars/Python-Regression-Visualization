# 🏠 Predicting House Pricing using various Regression Techniques and Plotting Actual v. Predicted Values

In this project, I use multiple **Regression** techniques, including **Linear, Polynomial, Ridge, and Lasso** to predict house prices based on income levels and visualize the results using **Matplotlib**

---

## 📊 Project Overview

This project is a beginner-level data science project that focuses on Regression techniques and plotting:
- Data creation
- Data processing and model training
- Batch and Stochastic Gradient Descent
- Linear, Polynomial, Ridge, and Lasso Regression
- Visualizations

This is more of a practice/learning exercise for beginners.

---

## 🧠 Skills Demonstrated

- Data creation and model training using **Sklearn**
- Data visualization using **Matplotlib**
- Regression using **Sklearn**
- Writing clean and well-documented Python code

---

## 🗂️ Dataset

I created my own randomized dataset for this project, though it was meant to mirror the California Housing dataset found on GitHub.
